# Changelog

## 1.0.0 — 3 November 2026

Initial complete browser-local learning release: six courses, 18 lessons, quizzes, progress, notes, bookmarks, 56-term glossary, three interactive labs, multi-board studio, validated backup/import, non-accredited learning records, instructor preview and GitHub Pages workflow.

Initial QA found and corrected a variable-font stylesheet export mismatch, a skip-link/HashRouter conflict, and print-record isolation. Browser acceptance tests run in the CI runner because the managed local runtime supports its own browser preview rather than standalone Playwright.
